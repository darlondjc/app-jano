Arquivos do logo do Jano, a chave de duas faces.

- `jano-simbolo-verde.svg`: símbolo em verde `#0E7C6B`, para fundos claros. Uma tinta só, fixa no arquivo (o `<img>` não herda cor).
- `jano-simbolo-branco.svg`: símbolo em branco, para fundos verdes ou escuros.
- `jano-icone-app.svg`: ícone do app, chave branca inclinada a 45° sobre `#0E7C6B`, 512 × 512, cantos de 23% do lado.

O nome "jano" não vem nos arquivos: componha com o símbolo e a fonte Inter 600 (veja o componente Logo). Respiro mínimo igual ao diâmetro do anel; tamanho mínimo de 16px para o símbolo.

- `jano-simbolo-verde-claro.svg`: o símbolo em verde claro (`#3CC4AB`), a versão do tema escuro para fundos `bg` e `surface` escuros.
