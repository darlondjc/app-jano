O chip filtra ou marca um recorte da lista; a tag de categoria rotula uma transação.

- Chip de filtro (`j-chip`): alterna com `aria-pressed`. Selecionado usa fundo `primary-soft`, texto `primary-text` e contorno `primary`. Altura de 32px, mas a área de toque deve chegar a 44px no celular com margem.
- Tag de categoria (`j-tag`): ponto de 8px na cor `cat-1` a `cat-8` da categoria, mais o nome. A cor nunca vem sozinha: o nome sempre aparece.
- Chips ficam em uma linha que rola na horizontal no celular, sem quebrar o rótulo.
- O consumidor fornece o texto, o estado e a ação ao tocar. Chips removíveis ganham um ícone de fechar com nome acessível ("Remover filtro Cartão").
